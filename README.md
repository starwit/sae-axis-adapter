# SAE axis-adapter

An SAE component to bridge MQTT messages generated by AXIS cameras 
with object detection ("AXIS Scene Metadata") to the SAE message format.

## How-To Run
- Make sure you have Poetry installed (recommended: use pipx, installable through apt)
- Run `poetry sync`
- Create a `settings.yaml` file from `settings.template.yaml`
- Run `poetry run python main.py`
